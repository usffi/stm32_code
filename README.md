# STM32 学习工程

从 GPIO 到电机闭环的嵌入式学习记录。

## 目标

面向嵌入式求职（机器人 / 运动控制方向），用一条主线贯穿全部练习：

> **一块 STM32 + 一台电机 + 一个编码器**

## 环境

| 项 | 内容 |
|---|---|
| 开发板 | STM32F103C8T6（江科大套件） |
| 核心 | Cortex-M3 / 72MHz / 64KB Flash / 20KB RAM |
| 编辑器 | VSCode + PlatformIO |
| 框架 | STM32Cube（HAL 库） |
| 调试器 | ST-Link V2 |

## 目录结构

```
stm32_code/
├── README.md          # 本文件
├── LOG.md             # 学习日志（做了什么 / 卡在哪 / 得到什么数字）
└── t01-blink/         # T01: GPIO 点灯
    ├── platformio.ini
    └── src/main.c
```

每个 `tXX-xxx` 是一个独立的 PlatformIO 工程，用 VSCode「打开文件夹」单独打开。

## 关键数字记录

| 节点 | Flash | RAM |
|---|---|---|
| T01 点灯 | 1208 B（1.8% / 64KB） | 44 B（0.2% / 20KB） |

> 记这两个数字，是为了对 20KB RAM 的约束建立实感。

## 备注

- `HAL_Init()` 后默认主频是 **HSI 8MHz**，不是 72MHz。手写工程没有 `SystemClock_Config()`，需要时自己补。
- PlatformIO 手写工程需要自己实现 `SysTick_Handler()`，否则 `HAL_Delay` 会卡死。
